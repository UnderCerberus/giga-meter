# 実機の検証結果

計測CSVは`probe-data/`に置き、リポジトリに入れない。この文書には結論のみ記載する。

| 確認項目 | 結果 | 判断 |
|---|---|---|
| `pdp_ip`の読み取り | 読める(2026-11-01、無料Apple ID署名) | 開発を継続 |
| モバイル回線の項目 | `pdp_ip0`、`pdp_ip2`などに分かれて値が入る | `pdp_ip`を合計する |
| 64ビット値の取得 | 取得できる。低い値では32ビット値と一致 | 64ビット値を優先。4.3GB超は未確認 |
| App Group | 署名プロファイルに許可なし | ウィジェットを廃止 |
| 入れ直し後の記録 | Documentsのデータは残る | 7日ごとの再署名でも記録を維持できる |
| 32ビット値の4.3GB周回 | 未実施 | 周回補正の要否 |
| 64ビット値の4.3GB超の正しさ | 未実施 | 採用する値 |
| 機内モードと回線切替 | 未実施 | 値が減少した場合の判定方法 |
| 再起動の検出 | 未実施 | 増分計算 |
| バックグラウンド更新の頻度 | 未実施 | 再起動で失う量の見積もり |
